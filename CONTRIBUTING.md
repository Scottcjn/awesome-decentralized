# Contributing to Awesome Decentralized

Thanks for helping curate the best P2P and decentralized applications!

## Quick Start

1. Fork this repository
2. Add your project to the appropriate category
3. Open a Pull Request

## Adding a Project

### Format

```markdown
* [Project Name](https://github.com/link): One-line description
```

### Status Indicators

- No indicator = Active project
- ☠️ = Old/unmaintained (use sparingly)

## Categories

- **Applications** - End-user P2P apps
- **Protocols** - Communication/networking protocols
- **Platforms** - Development platforms
- **Tools** - Developer utilities

## Quality Criteria

**Accepted:**
- ✅ Decentralized, P2P, or distributed architecture
- ✅ Working software (not just specs/whitepapers)
- ✅ Public repository or download

**Not accepted:**
- ❌ Centralized services claiming to be "decentralized"
- ❌ Vaporware without working code
- ❌ Projects that require paid access

## Pull Request Checklist

- [ ] Project is actually decentralized/P2P
- [ ] Added to correct category
- [ ] One-line description is clear
- [ ] Link works
- [ ] Alphabetically sorted within category
- [ ] Marked with ☠️ if unmaintained

## Updating Entries

You can also:
- Add ☠️ to dead projects
- Update descriptions
- Fix broken links
- Suggest category changes
